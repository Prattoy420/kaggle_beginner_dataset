# End-to-End Machine Learning Classification

An end-to-end supervised machine learning project using a Kaggle dataset, covering the complete workflow from exploratory data analysis to model evaluation.

## Project Overview

The goal of this project was to understand and implement a complete machine learning workflow on a real-world dataset.

The project covers:Exploratory Data Analysis (EDA), Data Cleaning,Missing Value Analysis,Outlier Detection and Handling,Feature Engineering,Categorical Encoding,Feature Scaling,Correlation Analysis,Feature Extraction using PCA,Supervised Classification,Model Comparison and Evaluation

## Machine Learning Workflow

Raw Dataset ->Data Understanding->EDA & Visualization->Data Cleaning->Outlier Detection & Handling->Feature Engineering->Encoding->Feature Scaling->PCA Feature Extraction->Classification Models->Different Model Evaluation & Comparison
## Classification Models

Supervised classification algorithms were trained and compared, including:

Logistic Regression,K-Nearest Neighbors (KNN),Decision Tree,Random Forest,Support Vector Machine (SVM)

## Key Learning

This project helped me understand the complete machine learning pipeline, especially the importance of data quality, preprocessing, feature transformation, dimensionality reduction, and model selection before deploying a classification model.
